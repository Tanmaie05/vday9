# Day 9: Student Records Using Python Lists

## Objective

The objective of this project is to develop a Student Record Program using Python lists. The application stores student names and marks and performs operations such as searching, sorting, and finding the highest and lowest scores. The project demonstrates practical list-processing skills and the use of Python built-in functions.

## Technologies Used

- Python
- VS Code

## Operations Supported

1. Add Student
2. View Student Records
3. Search Student
4. Sort Students by Marks
5. Find Highest Score
6. Find Lowest Score
7. Exit

## Features

- Stores student names and marks using Python lists.
- Allows users to add student records.
- Displays all student records.
- Searches for a student by name.
- Sorts students based on their marks.
- Finds the highest score.
- Finds the lowest score.
- Validates marks between 0 and 100.
- Handles invalid input.
- Uses separate functions for different operations.
- Provides a menu-driven command-line interface.

## Generated Files

- `student_records.py` – Contains the Python program for storing, searching, sorting, and processing student records.
